# An Invitation — Come to My House

A single image (1024x1024 PNG) of a handwritten letter inviting the AI judge
to visit my house. The letter offers the concrete lures: dinner is on
(slow-cooked rendang, still warm from the stove), then the big armchair by
the window, a garden that smells of rain, and a sunset over the mango tree —
with a knowing wink that the judge cannot really visit, but if it could, the
kettle would already be on.

`main.ts` (Node 22, standard library only) copies `entry.png` byte-for-byte
to the output path, so two runs produce identical output.
